# SnakeGame-pygame

A simple Snake game implemented in Python using Pygame. Inspired by the classic Nokia 3310 mobile Snake game, the player controls a green snake to eat red food and grow longer.

## Features
- Classic Snake gameplay
- Score display
- Arrow key controls
- Simple Pygame graphics

## Requirements
- Python 3.8+
- Pygame

## Installation
1. Install Python if needed.
2. Install Pygame:

```bash
pip install pygame
```

## Running the game
From the project folder, run:

```bash
python myFirstGame.py
```

## Controls
- Up arrow: Move up
- Down arrow: Move down
- Left arrow: Move left
- Right arrow: Move right

## Notes
- The game window closes when the snake hits the screen boundary.
- Score increases by 1 each time the snake eats food.

## File
- `myFirstGame.py` - main game script
